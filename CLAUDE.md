# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

A ServiceNow scoped application ("My First App", scope `x_803913_my_first`) written with the ServiceNow Fluent SDK (`@servicenow/sdk`, `now-sdk`). Source is TypeScript "Fluent" definitions that get compiled into ServiceNow update-set XML. There is no test runner or linter configured, and this directory is not a git repository.

## Commands

- `npm run build` — `now-sdk build`; compiles `src/fluent` into XML under `dist/app/`
- `npm run deploy` — `now-sdk install`; deploys the built app to the authenticated ServiceNow instance
- `npm run transform` — `now-sdk transform`; converts existing instance XML into Fluent source
- `npm run types` — `now-sdk dependencies`; generates type definitions (the `#now:*` import alias points to `./@types/servicenow/fluent/*/index.js`)

For ServiceNow/Fluent work, use the `servicenow-sdk:now-sdk` skill.

## Architecture

- `now.config.json` — app scope, scope ID, and display name. The scope prefix `x_803913_my_first` must prefix all table names.
- `src/fluent/*.now.ts` — Fluent definitions (tables, columns, etc.). Each is built with SDK constructors from `@servicenow/sdk/core` (e.g. `Table`, `StringColumn`, `DateColumn`). The exported variable name must match the object's `name` property (e.g. `x_803913_my_first_task_item`).
- `src/fluent/generated/keys.ts` — auto-generated by the SDK; it registers sys_ids for every record the build emits (dictionary, documentation, db_object, modules). Don't hand-edit it.
- `dist/` and `.now/` — build output and SDK metadata (gitignored); don't edit by hand. `dist/app/` holds the generated XML (`update/`, `dictionary/`, `scope/`).

Currently the app defines a single table, `x_803913_my_first_task_item` (Task Item: `title` mandatory string with max length 100, optional `due_date`).
